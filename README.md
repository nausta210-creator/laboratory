#Программа circle.cpp на C++

Программа запрашивает у пользователя радиус окружности и угол сектора в градусах, после чего вычисляет длину окружности, площадь круга и площадь кругового сектора.

Проверка корректности ввода:

    Если радиус меньше или равен нулю — выводится сообщение «Радиус должен быть положительным и не равным нулю!», программа завершается.

    Если угол выходит за пределы диапазона от 0 до 360 градусов — выводится сообщение «Угол должен быть от 0 до 360 градусов!», программа завершается.

Вычисления при корректных данных:

    Длина окружности: C = 2πr

    Площадь круга: S = πr²

    Площадь кругового сектора: S = (πr² × α) / 360°

Все результаты выводятся на экран. Для вычислений используется константа π = 3,14159265358979323846.
