# Треугольник: периметр, площадь и проверка на равнобедренность
Эта программа на C++ запрашивает у пользователя длины трёх сторон треугольника, вычисляет его периметр и площадь по формуле Герона, а также определяет, является ли треугольник равнобедренным. Перед вычислениями программа проверяет, может ли треугольник с такими сторонами существовать.
1. Пользователь вводит три вещественных числа — длины сторон a, b, c.
2. Программа проверяет условие существования треугольника: a + b > c && b + c > a && c + a > b.
Если условие не выполняется, выводится сообщение `"Такого треугольника не существует"` и программа завершается.
3. Если треугольник существует:
- Вычисляется периметр: perimetr = a + b + c.
- Полупериметр: p = perimetr / 2.
- Площадь по формуле Герона: ploshad = sqrt(p * (p - a) * (p - b) * (p - c)).
- Результаты выводятся на экран.
4. Затем проверяется, равнобедренный ли треугольник: a == b || b == c || a == c.
В зависимости от результата выводится соответствующее сообщение.
